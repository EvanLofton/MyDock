> 最大单个渲染进程 ~139 MB）。旧的 7.7 / 242 / 「7 个进程」是**加大文件夹 + 悬停标签之前**测的。
> 数据来源：`docs/soak-log.txt`（`scripts/soak.ps1` 每 120 秒采一行）。

> ⚠️ **内存这一行又变了（2026-09）**：右键菜单改成**独立 WebView 窗口**之后，
> WebView2 子进程从 6 个变成 7 个，私有内存 191 MB → **242 MB**（+51 MB）。
> 主进程本身没变（8 → 7.7 MB）。代价换来的东西是右键菜单**即时出现** ——
> 窗口在启动时就建好并隐藏；改成"第一次右键再建"的话，那一次右键要等
> WebView2 初始化几百毫秒，看起来像卡了。取舍记在 `docs/backlog.md`。

> ⚠️ **这一栏的数字改过两次，看清版本再引用。**
>
> 1. 旧文档的「前端轮询 CPU **0.08%**」——**错的**，差一个数量级，那是 4 秒轮询时代
>    且没记录测法。
> 2. 随后实测 1.5 秒轮询下是 **2.34%** ——数字对，但**归因错了**：当时以为是轮询
>    造成的。
> 3. 最终定位（2026-09）：2.34% 里**轮询只占 0.15%**，其余是 `reveal.rs` 主循环
>    **每 16ms 无条件调一次 `SetWindowPos`**（62.5 Hz × ~313µs ≈ 1.96%）。
>    加了「矩形没变就跳过」的判断后降到 **0.42 ~ 0.47%**。
>
> 测法（含 A/B 归因方法）见 [`backlog.md`](backlog.md) 附录 A。
> ⚠️ **测 CPU 必须关掉 `DOCK_DEBUG`** —— 它自身的开销比被测对象还大。

> ⚠️ 设计文档原写「Tauri 常驻内存 40-80 MB」，**实测证明是错的**，

## 自检脚手架与全部环境变量

> 从 README 搬过来（README 只留产品用的那几个变量）。**--features selftest 的构建里才有这些代码**，
> 产品构建里根本不存在。

### 自检环境变量表

自检脚手架 —— **必须 `cargo build --features selftest`**，产品构建里这些代码根本不存在：

> **自检只动它自己造的东西。** 它会在**你的真实配置的副本**上跑，最后要还原成原样 ——
> 所以 `restore_separators` 会**跳过** `original` 里已经存在的分割线与文件夹
> （用户可能本来就有文件夹，甚至有好几个同名的「新建文件夹」）。
> 早期版本"把所有文件夹都解散"，遇到这种配置会把用户的文件夹拆掉、里面的条目甩到顶层，
> 于是「测试结束后列表已还原」必然报红（实测 27 项被搞成 48 项）。
> 同理，涉及"移除了没有"的断言一律**按 id 判**，不按显示名 —— 名字不保证唯一。
>
> **两条已经踩过的自检坑**（都改成了"断言结果、容忍环境"）：
> 1. **合成点击偶尔会被吃掉一次**。实测"点外面关菜单"多数一次就成，偶尔第一次无效
>    （同一次运行里 Esc 那条路每次都准 → 分层逻辑没问题，是注入的问题）。
>    所以那两条断言改成"最多点两次，但**结果必须**是菜单关了、文件夹还开着"，
>    并把实际点了几次写进输出 —— 真正的回归（一次把两层都关掉）照样会被抓住。
> 2. **"本次含在跑的应用"不能当硬要求**：拖进文件夹的那个应用在不在跑取决于用户当时开着什么。
>    改成"一致性永远断言；有在跑的就要求点亮运行点，没有就只验一致性"并写明本次是哪种。

| 环境变量 | 作用 |
|---|---|
| `DOCK_SELFTEST=0` | 跳过焦点矩阵自检（默认会跑，会建辅助窗口） |
| `DOCK_LAYERTEST=0` | 跳过**层级自检**（默认跑：不用合成点击、不用辅助窗口，所以在任何环境下都能验证"Dock 不置顶 + 就在最底层"） |
| `DOCK_OPSTEST=1` | 额外跑「应用操作 + IPC 链路 + 设置窗口 + 拖放添加」自检 |
| `DOCK_DRAGPROBE=1` | 跑「指针拖出窗口后事件还在不在」实验（BL-4 前置，会合成一次鼠标拖拽） |
| `DOCK_DRAGTEST=1` | 跑 Dock 内拖拽自检（排序 / 拖出删除 / 非法顺序拒绝，**会临时改动并还原配置**，所以**必须同时设 `DOCK_CONFIG_DIR`**，否则直接拒绝跑） |
| `DOCK_MENUTEST=1` | 跑浮层（右键菜单 + 大文件夹）+ 分割线自检（**会临时改动并还原配置**，所以**必须同时设 `DOCK_CONFIG_DIR`**，否则直接拒绝跑） |
| `DOCK_MENUSHOT=<秒>` | 打开浮层并保持一段时间，用于**截图核对观感**（第一个条目是文件夹就展开文件夹，否则弹菜单；配 `DOCK_SELFTEST=0` 用） |
| `DOCK_LOCTEST=1` | 跑系统位置自检（**会真的开两个资源管理器窗口**验证「此电脑 / 回收站」能打开，跑完自动关掉） |
| `DOCK_ICONBOX=1` | 量「图标间距与图形留白」：布局间距 / 图标原始留白 / 渲染后的视觉间距（排查"某几个图标显得空"） |
| `DOCK_LAUNCH_TEST=<exe>` | 自检里额外验证启动（会真的拉起一个进程） |
| `DOCK_DUMP_APPS=1` | 启动后打印枚举到的应用（含图标提取结果与 alpha 统计） |
| `DOCK_NO_WINEVENT=1` | 关掉「桌面层被抬起」的 WinEvent 钩子，只留**点探测 + 前台轮询 + 500ms 兜底**。用于**分别**证明几条触发链各自有效（否则事件那条路会把别的功劳遮住 —— 这一轮排查就是这么发现"事件根本没送到"的） |
| `DOCK_DEBUG=1` | 调试日志（含桌面层守卫的逐帧明细：哪条触发源开的连扫、每次扫描的结果）。⚠️ 它自身开销比被测对象还大，**测 CPU 时必须关掉** |

> `p1-window-layer-findings.md` §6.6），代码和这个开关一起删掉了，现在只有亚克力一条路。
